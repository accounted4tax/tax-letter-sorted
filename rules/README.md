# Rules library

One JSON file per HMRC letter type, agreed with Eduard Husaru MAAT. The app reads these to recognise a letter, explain it and decide the appeal route.

| File | Letter |
|---|---|
| sa-late-filing-100.json | SA £100 late filing penalty (SA326D) |
| sa-late-filing-later.json | SA daily, 6-month and 12-month late filing penalties (SA370) |
| sa-late-payment.json | SA late payment penalties (SA370) |
| sa-notice-to-file.json | Notice to file a return (SA316) – explanation only |
| nudge-letters.json | Nudge letters incl. online platform sellers – explanation only |
| p800.json | P800 tax calculation – explanation only |
| simple-assessment.json | Simple Assessment (PA302) – explanation only |
| ct-late-filing.json | Corporation Tax late filing penalty – appeal letter |
| companies-house-late-filing.json | Companies House late filing penalty (not HMRC) – appeal letter |
