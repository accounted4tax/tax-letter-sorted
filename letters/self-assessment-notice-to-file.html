HMRC notice to file a Self Assessment tax return: what to do

A notice to file means HMRC wants a Self Assessment tax return from you for the tax year shown. Once you've been sent one, you have to file – even if you think you owe no tax.

Why you got this letter

HMRC sends a notice to file when it thinks you need to complete a tax return – for example because you've registered as self-employed, have rental or foreign income, earn above certain limits, or filed a return in the past. It can come as a letter or as an email to your online account.

Once a notice has been sent, the return is required. Not owing any tax doesn't stop the £100 penalty if the return is late.

If you don't think you need to file

Use HMRC's online checker to see whether you need a return. If you don't, tell HMRC before the deadline and ask it to withdraw the notice. If HMRC agrees, you won't get a penalty for that year.

Don't simply ignore the letter – if the notice stands and no return arrives, penalties start automatically. How the £100 late filing penalty works.

What you'll need to file

  • your Unique Taxpayer Reference (UTR) and Government Gateway sign-in
  • your income for the tax year (6 April to 5 April): self-employment, rent, pay (P60), pensions, savings interest
  • details of any other income earned throughout the tax year
  • your expenses, if you're self-employed or a landlord
  • any pension contributions or Gift Aid donations

Questions

Do I have to file if I don't owe any tax?

Yes, once HMRC has sent a notice to file – unless you ask HMRC to withdraw it before the deadline and it agrees. Otherwise the £100 late filing penalty still applies.

I got the notice in December. When is my deadline?

If the notice is dated after 31 October, you have 3 months from the date of the notice to file. Tax is still due by 31 January.

How do I know if I really need a tax return?

Use HMRC's online checker on GOV.UK. If it says you don't need one, contact HMRC before the deadline and ask it to cancel the notice.
